# VÉLORA — Premium Property Care

Multipage static website concept for VÉLORA, with a consistent glassmorphism design system inspired by the PRDXQ visual language.

## Pages
- `index.html` — Home
- `leistungen.html` — Services
- `mitgliedschaft.html` — Membership tiers and calculator
- `ablauf.html` — Process
- `kontakt.html` — Inquiry prototype
- `impressum.html` and `datenschutz.html` — legal placeholders requiring completion

## Design
- Responsive desktop/mobile navigation
- Layered glass surfaces, blur, soft depth and light reflections
- Light theme by default with a dark-theme toggle
- Reduced-motion support
- Shared CSS and JavaScript across all pages

## Important before launch
- Prices and included hours are illustrative draft assumptions, not validated commercial terms.
- The inquiry form does not transmit or store data. It only creates a copyable text locally.
- Legal pages are placeholders and must be completed and reviewed before public commercial use.
- Confirm business identity, service scope, permissible trades, insurance, VAT, pricing, travel and contractual terms.
- Consider self-hosting fonts and add a real secure backend/CRM before collecting customer inquiries.
