# VÉLORA — Premium Property Care

Responsive German-language landing page concept for a portfolio-based property maintenance membership.

## Current scope
- Premium responsive landing page
- Service overview and membership positioning
- Illustrative tier pricing and portfolio calculator
- FAQ explaining unlimited requests vs. capped included labour
- Inquiry form prototype that formats and copies an inquiry locally

## Important product assumptions
The pricing and included labour hours are **draft hypotheses**, not validated commercial terms. The current concept separates unlimited issue/request submissions from a defined annual labour allowance pooled across all registered units. Additional work, travel, material, VAT treatment, response times and exclusions must be defined in a reviewed contract before launch.

## Run locally
Open `index.html` in a browser. No build step or package manager is required.

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. GitHub will show the published URL after deployment.

## Before accepting customers
- Verify the brand name and trademark availability.
- Confirm permissible trades and registration requirements with the local Handwerkskammer.
- Finalize pricing from real travel, labour, insurance and overhead costs.
- Add a real backend/CRM and secure inquiry delivery; the current form does not transmit or store submissions.
- Add legal notice, privacy policy, terms, cancellation and consumer information.
- Confirm insurance cover and define service territory, availability and emergency exclusions.
